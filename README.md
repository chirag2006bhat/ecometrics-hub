# 🌍 EcoMetrics Hub

**Live App:** [https://ecometrics-hub.vercel.app](https://ecometrics-hub.vercel.app)

EcoMetrics Hub is a real-time environmental compliance and monitoring dashboard. It visualizes critical municipal data (Water Quality, Soil Analysis, Food Safety) and features a hybrid AI assistant to analyze thresholds and provide instant compliance reporting.

## 🚀 Key Features
* **Live Interactive Mapping:** Visualizes safe, warning, and danger zones dynamically using Leaflet.js.
* **AI-Powered Analytics:** Integrated with Google Gemini to generate executive compliance reports and predictive risk alerts.
* **Dynamic Filtering:** Sort live parameters by location, testing type, and historical timelines.
* **Serverless Architecture:** Frontend hosted on Vercel, querying a live Google Apps Script database backend.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript, Leaflet.js
* **Backend:** Google Apps Script, Google Sheets API
* **AI Integration:** Google Gemini API 
* **Deployment:** Vercel
